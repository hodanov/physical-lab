# ADR-0002: 左右間接続に USB-C を使う

- 状態: 承認
- 日付: 2026-11-24

## 背景

[ADR-0001](0001-mac-oriented-split-membrane-scissor.md) で、左半分をメイン
ユニットとし、右半分は左右間ケーブルで給電・通信すると決めた。ケーブルの
コネクタは未定で、CAD の背面壁の開口はプレースホルダのままだった。

筐体は薄型で、現在の CAD では内部の高さ（`interior_depth`）が 5 mm しかない。
右半分の電源は左半分のバッテリーから供給するため、コネクタの抜き差しで電源が
短絡しないことも求められる。

## 決定

- 左右間接続のコネクタに USB-C を使う。左右それぞれの背面壁に USB-C
  レセプタクルを置き、市販の C-C ケーブルでつなぐ。
- 左右間ポートは USB ホスト接続に使わない。ホスト接続は引き続き左半分の外側
  側面の USB-C ポートだけが担う。
- 左右間ポートには、ホストや充電器を誤って挿しても壊れない保護を持たせる。
  具体的な回路（給電の開始条件、通信に使う信号線）は PCB 設計時に決める。

## 検討した選択肢

- TRRS（3.5 mm 4極）: 自作キーボードで一般的で、部品とケーブルが安く手に入る。
  一方、一般的なジャックは本体の高さが 5 mm 前後あり、基板を含めると今の内部の
  高さに収まらない。プラグも太く、開口は直径 6〜7 mm 程度が必要になる。挿抜時に
  プラグ先端が接点をなぞって電源と信号が一時的に短絡するため、バッテリーから
  給電する構成では保護回路か運用上の注意が要る。
- USB-C: 薄型のレセプタクルがあり、今の 3.5 mm 高の開口に近い寸法で収まる。
  挿抜時の短絡が起きにくく、向きを問わない。一方、ホストや充電器を誤って挿す
  可能性があり、VBUS の逆流などに対する保護が必要。部品単価は TRRS より高い。

## 影響

- 薄型の筐体と、MacBook Air に近い外観の目標を保てる。
- 左右間ポートの誤挿し保護が PCB 設計の要件になる。ホスト用ポートと区別できる
  よう、筐体か刻印で左右間ポートを示すことも検討する。
- 背面壁の開口寸法は、採用するレセプタクルのデータシートで確定するまで
  プレースホルダのままとする。部品の寸法は一般的な値に基づいており、特定部品の
  データシートでは未確認。
- 同じ変更で README の確定仕様とプロダクトの `AGENTS.md` を更新する。
