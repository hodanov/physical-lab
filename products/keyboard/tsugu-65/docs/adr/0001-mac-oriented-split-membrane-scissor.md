# ADR-0001: Mac指向の分割メンブレン・シザー構成

- 状態: 承認
- 日付: 2026-09-22

## 背景

TSUGU Split 65は、MacBook AirまたはMacBook Proのキーボードを日常的に使う人が、
外付けキーボードへ自然に移行できることを目指す。同時に、左右を独立配置できる
分割構造、薄さ、軽さ、MacとiPadを切り替えるBluetooth接続を求める。

既存のAlice配列、MX互換スイッチ、トレイマウントという初期案は、配列の移行負荷と
全高の面でこの目的に合わない。

## 決定

- US ANSIの65%クラス、66キー配列を採用する。ファンクション列は置かない。
- `6/T/G/B` と `7/Y/H/N` の間で左右に分割する。通常のMac系の行スタッガーを保ち、
  大きな内向き角度や列スタッガーは採用しない。
- `fn` を上矢印の右隣に置き、数字列へのレイヤーでF1〜F12を提供する。
- キー機構はメンブレンとシザーを組み合わせる。初号機では、互換性を検証した
  ドナーキーボードのシザー機構、シリコンドーム、キーキャップを流用できる。
- 左半分をメインユニットとし、USB-C、Bluetooth、バッテリー、アンテナ、3台の
  Bluetoothプロファイルを切り替える専用操作を持たせる。右半分はケーブルで
  左半分に接続して給電・通信する。
- Bluetooth性能を守るため、筐体は非金属を標準とする。

## 検討した選択肢

- Alice配列とMX互換メカニカル: 既存の自作キーボード部品を活用しやすく、
  スイッチ交換も容易。しかしMacBookからの配列差が大きく、薄型化に不利。
- ロープロファイルメカニカル: 薄く、スイッチ交換や調整がしやすい。しかし
  MacBook Airに近いシザーの打鍵感を直接には再現しにくい。
- メンブレン + シザー: 最も薄く、目標とする打鍵感に近い。高精度なシザー固定、
  部品供給、耐久性の検証が必要。
- 左右完全無線: 設置の自由度は高い。しかし各半分に電池と無線回路が必要になり、
  薄さ、重量、同期、保守性で不利。

## 影響

- 物理配列、キーキャップの入手、シザー固定プレート、メンブレンFPCを中心に
  試作を進める。
- ドナー部品を使う初号機は検証専用とし、量産可否は独立した部品供給と権利確認後に
  判断する。
- 金属筐体、テンティング、ホットスワップは初号機の必須要件から外す。
- ファームウェアはUSB-CとBluetooth 3台のホスト切替、Fnレイヤー、Globeキーを
  実装する必要がある。
