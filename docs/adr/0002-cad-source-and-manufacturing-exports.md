# ADR-0002: CAD 正本と製造用エクスポート

- 状態: 承認
- 日付: 2026-09-22

## 背景

物理設計には、編集可能な元モデルと、製造・3Dプリント向けの中立形式ファイルの両方が
必要。成果物のライフサイクルを明確にしないと、エクスポート済みファイルが CAD 正本と
乖離し、意図しないリビジョンを製造するリスクがある。

## 決定

主 CAD ツールには FreeCAD を使い、既定の単位はミリメートルとする。

- `cad/source/` の `.FCStd` を編集可能な設計正本として扱う。
- 製造データ交換向けに中立形式の STEP を生成する。
- 3Dプリントワークフロー向けに STL を生成する。
- 生成した STEP と STL は `cad/export/` に置き、手で編集しない。

CAD 正本を変えたら、レビューや製造の前に対応するエクスポートを再生成する。

## 検討した選択肢

- CAD 正本とエクスポートを同じ場所に置く: ディレクトリは少ないが、編集可能な設計と
  生成済み成果物の区別が曖昧になる。
- STL を唯一の正本にする: 3Dプリントとの互換性は高いが、編集可能な CAD 正本や中立な
  交換形式には適さない。
- FreeCAD 正本を STEP・STL エクスポートから分離する: 編集可能な設計を保持でき、
  製造成果物のライフサイクルを明示できる。

## 影響

- CAD を変えたら、発注前にエクスポートの再生成と検査が必要になる。
- 素材別の設計ガイドラインは製造上の判断として扱い、選んだサービス・素材ごとに確認
  する。
- 既定の CAD ツールや単位を意図的に変える場合は、プロダクト文書で明記する。
