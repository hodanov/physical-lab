# ADR-0001: 物理プロダクトのモノレポ構成

- 状態: 承認
- 日付: 2026-09-22

## 背景

このリポジトリでは複数の物理プロダクトを設計、試作、製造する。最初のプロダクトは
キーボードだが、将来はロボット、筐体、治具、電子工作へ広がる可能性がある。無関係な
プロダクトを密結合させずに、共通の CAD・電子回路資産を置ける安定した場所が必要。

## 決定

このリポジトリを物理プロダクト開発のモノレポとして使う。

- 個別プロダクトは `products/<category>/<product>/` に置く。
- 再利用する CAD・電子回路資産は `libraries/` に置く。
- 共通の開発・製造ユーティリティは `tools/` に置く。
- リポジトリ全体の文書は `docs/` に置く。

最初のプロダクトは `products/keyboard/tsugu-65/` とする。各プロダクトは CAD、図面、
PCB、ファームウェア、BOM、製造記録、プロダクト固有の ADR を所有する。

## 検討した選択肢

- キーボードのディレクトリをリポジトリルートにする: 単一プロダクトなら単純だが、
  他種プロダクトへきれいに拡張できない。
- プロダクトごとに別リポジトリを使う: プロダクトは隔離できるが、共通の開発規約や
  再利用資産の管理が難しくなる。
- 物理プロダクトのモノレポを使う: プロダクト境界を保ちつつ、再利用資産と全体方針を
  共有できる。

## 影響

- 新しいプロダクトはリポジトリルートではなく、プロダクトカテゴリ配下に作る。
- 共通資産は、複数プロダクトで実際に使われるまでは `libraries/` へ移さない。
- 全体方針は `docs/adr/`、プロダクト固有の決定は対象プロダクト配下に記録する。
